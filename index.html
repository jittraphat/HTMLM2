เว็บเพจและศัพท์เบื้องต้น

รู้จักเว็บเพจ ประโยชน์ในชีวิตประจำวัน และคำศัพท์ที่ควรรู้ก่อนสร้างเว็บ

เว็บเพจคืออะไร

นิยามเว็บเพจ คือ “เอกสารที่ใช้ในการเผยแพร่ข้อมูลข่าวสาร” ซึ่งประกอบด้วย ข้อความ ภาพ เสียง และภาพยนตร์ ผ่านทางเครือข่ายอินเทอร์เน็ต

ลองคิดก่อนนักเรียนคิดว่าเว็บเพจมีประโยชน์อะไรบ้างในชีวิตประจำวัน

ดูประโยชน์ของเว็บเพจ
  • ข่าวและเหตุการณ์ในปัจจุบัน
  • ข้อมูลความรู้และห้องสมุด
  • ประชาสัมพันธ์บริษัทและองค์กร
  • ความบันเทิง
  • การเงิน การลงทุน
  • ซื้อ-ขายสินค้าและบริการ
  • ดาวน์โหลดข้อมูล
  • บริการติดต่อสื่อสาร

เว็บเพจมาถึงหน้าจอเราได้อย่างไร

คำศัพท์เบื้องต้นเกี่ยวกับเว็บไซต์

Internet

ระบบเครือข่ายคอมพิวเตอร์ที่ใหญ่ที่สุดในโลก เกิดจากการเชื่อมโยงของคอมพิวเตอร์หลายล้านเครื่องที่กระจายอยู่ตามที่ต่างๆ ในโลก

WWW World Wide Web

บริการข้อมูลที่อยู่ในรูปเอกสารแบบ Hypertext ภายในเอกสารมีจุดเชื่อมโยง (link) ไปยังเอกสารอื่นๆ ที่เกี่ยวข้อง เหมือนใยแมงมุม จึงเป็นที่มาของคำว่า Web

HTTP HyperText Transfer Protocol

โปรโตคอลสำหรับเปิดดูข้อมูลจาก www เรียกใช้โดยระบุ http:// และตามด้วย URL ในช่อง Address ด้านบนของโปรแกรมเว็บบราวเซอร์

เว็บเพจ Web Page

คำที่ใช้เรียกหน้าเอกสารต่างๆ ที่อยู่ในรูปแบบไฟล์ HTML เปรียบเสมือนหน้ากระดาษแต่ละหน้าในนิตยสาร แต่ต่างกันตรงที่มีการเชื่อมโยง (Link) ให้คลิกไปหน้าอื่นได้

โฮมเพจ Home Page

คำที่ใช้เรียกหน้าแรกของเว็บไซต์ ประกอบด้วยเมนูและเรื่องราวต่างๆ คล้ายหน้าปกนิตยสาร ถ้าออกแบบให้สวยงามและน่าสนใจ ผู้ชมก็จะแวะเข้ามาเยี่ยมชมมากขึ้น

เว็บไซต์ Web Site

กลุ่มของเว็บเพจ ภายในเว็บไซต์ประกอบด้วยโฮมเพจและเว็บเพจ มักใช้เรียกเว็บที่มีขนาดใหญ่และจดทะเบียนชื่อ (Domain Name) ไว้แล้ว เช่น http://www.yahoo.com

Web browser

โปรแกรมสำหรับเรียกดูเว็บเพจ โดยจะแปลคำสั่ง HTML แล้วประมวลผลเพื่อแสดงเป็นเว็บเพจ เช่น Chrome, Edge, Firefox, Safari และ Opera

Web server

เครื่องคอมพิวเตอร์ที่ให้บริการข้อมูลใน www เก็บเว็บเพจและโปรแกรมจัดการบริการ เมื่อผู้ใช้อยากดูเว็บเพจก็ใช้เบราว์เซอร์เรียกขอข้อมูลด้วยที่อยู่ที่เรียกว่า URL

Upload

การส่งข้อมูลจากเครื่องของเราไปยัง Web Server เมื่อสร้างเว็บเพจเสร็จแล้วต้องส่งไฟล์ไปเก็บไว้ที่เซิร์ฟเวอร์ โดยอาศัยโปรแกรม FTP

Download

การรับหรือบันทึกข้อมูลจากเครื่อง Server / Web Server ที่ให้บริการข้อมูลมาเก็บไว้ที่เครื่องคอมพิวเตอร์ของตนเอง

Search engine

เครื่องมือหรือโปรแกรมค้นหาเว็บต่างๆ โดยเก็บรายชื่อเว็บไซต์และข้อมูลที่เกี่ยวข้องไว้ใน server เพื่อให้ค้นหาและแสดงผลได้สะดวกรวดเร็ว เช่น google.com, bing.com, yahoo.com

URL และโดเมนเนม

ที่อยู่ของเว็บเพจอ่านอย่างไร และชื่อเว็บไซต์ถูกตั้งขึ้นมาอย่างไร

URL คือที่อยู่ของข้อมูลบนอินเทอร์เน็ต

URL (Uniform Resource Locator) คือข้อความที่บอกตำแหน่งของข้อมูลใน Internet ไม่ว่าจะเป็น Web page หรือไฟล์ประเภทต่างๆ เช่น รูปภาพ เสียง URL ประกอบด้วย โปรโตคอล + domain name + directory ที่เก็บไฟล์ + ชื่อไฟล์

สังเกตแถบที่อยู่ด้านบนของเว็บนี้แถบที่อยู่ในหัวเว็บใช้สี 4 สีแบบเดียวกับรูปนี้ เพื่อให้เห็นว่า protocol, domain, path และ webpage แยกกันอย่างไร

โดเมนเนม (Domain Name)

การติดต่อกันบนอินเทอร์เน็ตใช้ ไอพีแอดเดรส (IP Address) ในการทำงาน แต่เป็นตัวเลขยาวๆ ทำให้ผู้ใช้จำยาก จึงมีการใช้ โดเมนเนม หรืออินเทอร์เน็ตแอดเดรส (Internet Address) ซึ่งเป็นตัวอักษรที่จำง่ายมาใช้แทนไอพีแอดเดรส โดเมนเนมจะไม่ซ้ำกัน และมักตั้งให้สอดคล้องกับชื่อบริษัทหรือองค์กรเจ้าของ เพื่อสะดวกในการจดจำ เช่น บริษัท ดีแทค มีโดเมนเป็น www.dtac.co.th

เริ่มต้นกับการสร้างเว็บเพจด้วย HTML

รู้จักภาษา HTML แท็กเปิด แท็กปิด และโครงสร้างของเอกสารที่ทุกเว็บเพจต้องมี

HTML คืออะไร

HTML ย่อมาจาก HyperText Markup Language เป็นภาษาที่ใช้เขียนเพื่อกำกับข้อมูลต่างๆ และทำงานร่วมกับ web browser เป็นภาษาพื้นฐานที่สุดที่ใช้พัฒนาเว็บไซต์ ปัจจุบันพัฒนาภายใต้การดูแลขององค์กรชื่อ World Wide Web Consortium (W3C) และเวอร์ชันปัจจุบันคือเวอร์ชัน 5 หรือที่เรียกกันว่า HTML5

รูปแบบการเขียนของ HTML

HTML เขียนในลักษณะ TAG (แท็ก) ซึ่งมีทั้งแท็กเปิดและแท็กปิด โดยแท็กปิดจะมีเครื่องหมาย slash (/) นำหน้าชื่อแท็ก

โครงสร้างของ HTML

เอกสาร HTML มีโครงสร้าง 2 ส่วน คือ HEAD สำหรับข้อมูลในส่วนหัวของเอกสาร เช่น ข้อความบน Title bar ของ web browser และ BODY สำหรับแสดงผลบนหน้าเอกสาร หรือหน้า web browser

<!DOCTYPE html>
ประกาศว่าเอกสารนี้ใช้ HTML5
<html>
แท็กอันแรกสุด ครอบเนื้อหาทั้งเอกสาร และปิดด้วย </html> เป็นแท็กสุดท้าย
<head>
ส่วนหัว (header) ของเอกสาร
<body>
ส่วนเนื้อหาที่แสดงบนหน้าเว็บ

HEAD section

ส่วน HEAD เป็นส่วนที่ใส่คำอธิบายเว็บเพจ เช่น TITLE หรือชื่อเรื่องของเอกสาร, KEYWORD สำหรับการค้นหา หรืออื่นๆ โดยเขียนแท็กในกลุ่มนี้ไว้ภายใน <head>…</head>

เขียนภาษาไทยให้ถูกต้องใส่ <meta charset="utf-8"> ไว้ใน head และตอนบันทึกไฟล์ใน Notepad ให้เลือก Encoding เป็น UTF-8 เพื่อไม่ให้ตัวอักษรไทยเพี้ยน

BODY section

ส่วน BODY เป็นส่วนที่จะแสดงผลไปยังหน้า web browser เช่น การแสดงรูปภาพ การแสดงเนื้อหา การสร้างจุดเชื่อมโยงหรือลิงก์ โดยเขียนแท็กในกลุ่มนี้ไว้ภายใน <body>…</body>

เริ่มเขียน HTML โดยใช้ Notepad

  1. เปิด Notepadโปรแกรม Text Editor ที่มีมากับ Windows
  2. พิมพ์โค้ด HTMLเริ่มจากโครงสร้างพื้นฐาน แล้วเติมข้อความลงในส่วน head และ body
  3. บันทึกไฟล์เลือก File > Save As ตั้งชื่อไฟล์ให้ลงท้ายด้วย .html เลือก Save as type เป็น All Files และ Encoding เป็น UTF-8
  4. เปิดดูในเว็บเบราว์เซอร์ดับเบิลคลิกไฟล์ที่บันทึกไว้ เบราว์เซอร์จะแปลคำสั่งและแสดงเป็นหน้าเว็บ
  5. แก้ไขแล้วดูผลใหม่แก้โค้ดใน Notepad บันทึกไฟล์ แล้วกดรีเฟรชหน้าเว็บในเบราว์เซอร์

การใส่สีในเว็บเพจ

สีในคอมพิวเตอร์เกิดขึ้นจากการผสมค่าสีโหมด RGB ซึ่งประกอบด้วยสี 3 สี คือ Red (แดง) Green (เขียว) และ Blue (น้ำเงิน) เราสามารถกำหนดค่าสีได้ 2 แบบ

1. ชื่อสี

ระบุชื่อสีลงไปเลย เช่น red blue yellow

2. ค่าสี

ระบุเป็นเลขฐาน 16 (0-9 หรือ A-F) ทั้งหมด 3 ชุด ชุดละ 2 ตัว คือ แดง เขียว น้ำเงิน (RGB) และต้องเขียนหลังเครื่องหมาย # เช่น #FFFFFF ได้สีขาว, #000000 ได้สีดำ

ในเลขฐาน 16 ตัว 0 มีค่าสีน้อยที่สุด และ F มีค่าสีมากที่สุด

กำหนดทิศทางการวิ่ง direction

เพิ่มแอตทริบิวต์ direction ในแท็กเปิด <marquee> เพื่อเลือกว่าข้อความจะวิ่งไปทางไหน ถ้าไม่ใส่ ข้อความจะวิ่งจากขวาไปซ้าย

คำสั่งผลที่ได้
direction="up"วิ่งจากล่างขึ้นบน
direction="down"วิ่งจากบนลงล่าง
direction="left"วิ่งจากขวาไปซ้าย (ค่าปกติ)
direction="right"วิ่งจากซ้ายไปขวา
เกร็ดข้อความที่วิ่งขึ้นหรือลงต้องมีพื้นที่ให้วิ่ง เบราว์เซอร์บางตัวถ้าไม่กำหนดความสูง กรอบจะสูงแค่บรรทัดเดียว จึงเห็นข้อความแค่แวบเดียว ให้ใส่ height="100" ในแท็ก <marquee> ดังตัวอย่าง

กำหนดรูปแบบการวิ่ง behavior

เพิ่มแอตทริบิวต์ behavior เพื่อเลือกว่าข้อความจะวิ่งอย่างไรเมื่อไปถึงขอบ ถ้าไม่ใส่ ข้อความจะวิ่งแบบ scroll

คำสั่งผลที่ได้
behavior="alternate"วิ่งกระทบขอบแล้วเด้งไปอีกทาง กลับไปกลับมา
behavior="slide"วิ่งแล้วหยุดที่ขอบ
behavior="scroll"วิ่งหายไปจากขอบ และปรากฏที่ขอบอีกด้าน ทำซ้ำเรื่อยๆ (ค่าปกติ)

การแทรกรูปภาพ

ชนิดของไฟล์ภาพ คำสั่งแทรกรูป ข้อความกำกับ ขนาด และกรอบรูป

ชนิดของแฟ้มข้อมูลรูปภาพ

รูปภาพเป็นสิ่งสำคัญอย่างมากในการสร้างเว็บเพจ ช่วยให้ผู้อ่านเข้าใจเรื่องราวมากขึ้นและทำให้เว็บเพจมีสีสันสวยงาม สิ่งที่ต้องคำนึงถึงคือ ภาพควรมีขนาดเล็ก เพื่อให้เรียกใช้บนเว็บเพจได้อย่างรวดเร็ว การนำภาพกราฟิกมาใช้ในเว็บเพจนิยมใช้ 3 ฟอร์แมต คือ .jpg .gif และ .png เพราะแต่ละแบบมีลักษณะการบีบอัดข้อมูลต่างกัน เลือกใช้ตามความเหมาะสม

.jpg (JPEG)

Joint Photographic Experts Group นิยมใช้บนอินเทอร์เน็ต ความละเอียดสูง ใช้สีได้มากถึง 24 บิต (16 ล้านสี) เหมาะกับภาพถ่าย

ข้อด้อย: ทำพื้นของรูปให้โปร่งใสไม่ได้

.gif (GIF)

Graphics Interchange Format รองรับสีสูงสุดเพียง 8 บิต (256 สี) เหมาะกับโลโก้ ภาพการ์ตูน คลิปอาร์ต ความจุต่ำ ทำพื้นหลังโปร่งใสได้ และทำภาพเคลื่อนไหวได้

.png (PNG)

Portable Network Graphics รวมจุดเด่นของ JPG และ GIF รองรับสีถึง 24 บิตเหมือน JPG ทำพื้นหลังโปร่งใสได้เหมือน GIF และมีความจุต่ำ

การสร้างตารางในเว็บเพจ

โครงสร้างตาราง หัวตาราง เส้นขอบ คำอธิบาย ระยะห่าง และขนาดของตาราง

ตารางใช้ทำอะไร

การใช้ตารางเหมาะสำหรับการนำเสนอข้อมูลจำนวนมาก เช่น ข้อมูลการซื้อขายหลักทรัพย์ ยอดขายสินค้าของบริษัท ข่าวสารทั่วไป หรือสรุปปริมาณสินค้าคงคลังที่ควรนำมาจัดในรูปแถวและหลัก นอกจากนี้ตารางยังช่วยจัดองค์ประกอบต่างๆ ในเว็บเพจให้อยู่ในตำแหน่งที่ต้องการได้อย่างเป็นสัดส่วนอีกด้วย

โครงสร้างและคำสั่งในการสร้างตาราง

โครงสร้างด้านล่างสร้างตารางที่มี 3 แถว และ 2 คอลัมน์ (แถวแรกเป็นหัวตาราง)

<caption>

<tr>

กำหนดหัวเรื่องในคอลัมน์ ปิดด้วย </th> (จะมีหรือไม่มีก็ได้)

การปรับขนาดช่องเซลล์ (colspan และ rowspan)

ตารางปกติ ช่องเซลล์ 1 ช่องมีขนาด 1 แถว 1 คอลัมน์ ถ้าต้องการให้เซลล์กว้างเกิน 1 คอลัมน์ หรือสูงเกิน 1 แถว เพื่อจัดรูปแบบข้อมูลตามต้องการ ทำได้ดังนี้

colspan

การกำหนดสีของลิงก์

ปกติถ้าไม่กำหนดสีของลิงก์ ลิงก์จะเป็นสีน้ำเงินและมีขีดเส้นใต้ เปลี่ยนสีได้เพื่อความสวยงาม และไม่ให้สีลิงก์กลืนกับสีพื้นหลัง ลิงก์มีสถานะต่างกัน 3 แบบ

link

vlink

สีของลิงก์ที่เคยถูกคลิกไปแล้ว (Visited Hyperlink)

alink
